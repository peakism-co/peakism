# ∧ Peakism

Peakism is an independent, for-profit organisation. **We do everything** —
software, content, systems, and whatever comes next. It is, plainly, an
organisation of the unemployed.

- **Site** — https://peakism.is-local.org
- **Mirror** — https://peakism.pages.dev
- **GitHub** — https://github.com/peakism-co
- **Contact** — 84sofik@gmail.com

## What that has meant so far

| Area | What it means |
| --- | --- |
| **Software** | Apps and tools people keep open all day. Native where it matters, quiet everywhere else. |
| **Content** | Writing, video and visuals, made in-house and published under our own name. |
| **Systems** | APIs, services and cloud pieces that stay up without a team watching them. |
